Projects

01 ↗

Offr+ — Networking Pipeline for Finance Students

A pipeline for moving and organizing contacts from cold outreach through to real connections. About 9,800 lines across 11 pages, backed by 13 Postgres tables with 39 row-level security policies and three Supabase Edge Functions handling Microsoft Graph calendar sync, Teams meeting creation, and a cached job feed. I built my skills with React, Postgres, and OAuth mostly by breaking this software apart and working out the problems. Still a work in progress, and the project I'm most excited to keep building.

02 ↗

Ad+ — E-Commerce Advertising Platform

Local-first advertising dashboard shipped as a single self-contained HTML file — zero frameworks, zero backend. Four integrated modules: trending-product tracker, drag-and-drop kanban pipeline, automated outreach-letter generation, and a client-communication organizer.

03 ↗

AI Doctor — Cross-Platform AI Healthcare App

LLM-powered mobile app delivering symptom assessment, emergency detection, and provider suggestions — presented at Google DevFest. Dockerized FastAPI backend with layered LLM safety controls: guardrails and JSON-schema output validation.

AI-Server — Multi-Provider LLM API Server

Production-ready inference gateway unifying OpenAI, Anthropic, and Google LLM providers behind one REST interface — async request handling, token-streaming responses, Pydantic validation, per-client rate limiting, and structured logging.
